After making code changes in this repo, run `just quality`. It checks formatting, typechecks, strict clippy linting, the full test suite, and coverage.

## Experiments

- Recall/memory experiment methodology lives in `experiments/recall/README.md`. Follow its sampling, significance, holdout, and replay-vs-rerun rules for any backtest: screen on the frozen ~200-anchor library, replay saved candidates when only reranking/selection changed, rerun retrieval only when candidate generation or query construction changed, and reserve full-corpus replays for corpus-wide lifecycle effects.
- Report paired bootstrap confidence intervals; treat deltas whose interval includes zero as no detectable effect. Confirm winners on the holdout anchor set before shipping.
- The experiment backlog and durable results live in `EXPERIMENTS_LOG.md`. Phase 0 (validation infrastructure) gates ship/no-ship decisions, not exploration; the next decision-quality run is the lowest incomplete Phase 0 item. New experiment ideas are appended to the backlog with a hypothesis, target metric (or the question a diagnostic answers), and measurement mode — experiment-sized ideas go there, not in `ROADMAP.md`.
- When an item is addressed, follow the "When an item is addressed" policy in `EXPERIMENTS_LOG.md`: completed Phase 0 prerequisites stay listed with a DONE date; completed experiments delete their backlog entry, get a dated decision record, and commit run artifacts under `experiments/recall/<date>-<name>/` (forward/memory-write experiments must also satisfy the forward-experiment artifact contract in `experiments/recall/README.md`).
